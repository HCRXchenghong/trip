# 旅行 plan

这是一个独立运行的旅行行程网页，当前版本用于记录 **2026 年 10 月 2 日—8 日的哈尔滨、齐齐哈尔、呼伦贝尔、阿尔山自驾路线**。

项目没有 npm 第三方依赖：Node.js 自带 HTTP 服务和 SQLite，后端负责 API 与静态文件，浏览器端负责地图、行程卡片、图片弹窗和动态线路播放。

## 一次启动

环境满足要求后，在项目目录执行下面一条命令即可：

```bash
npm start
```

然后打开：<http://127.0.0.1:3030/>

完整命令如下，后面换电脑或重新打开项目时也按这个顺序执行：

```bash
cd "/Users/seron-cheng/Desktop/旅行plan"
npm start
```

停止服务：在运行服务的终端按 `Ctrl+C`。

### 运行要求

- Node.js **22.5.0 或更高版本**。项目使用 Node 内置的 `node:sqlite`，不需要单独安装 SQLite 或 npm 包。
- 浏览器建议使用 Chrome、Edge 或 Safari 的最新版。
- 高德 JS Key 用于显示地图；没有 Key 时服务仍能启动，但页面会显示地图配置提示，地图本身不会初始化。

检查 Node 版本：

```bash
node --version
```

## 首次配置

项目根目录已经提供 `.env.example`。如果当前目录还没有 `.env`，执行：

```bash
cp .env.example .env
```

再按下面的说明填写 Key。已经存在并可用的 `.env` 不需要重复复制，也不要把 `.env` 提交到仓库。

### 环境变量

| 变量 | 是否必填 | 用途 |
| --- | --- | --- |
| `AMAP_JS_KEY` | 显示地图时必填 | 浏览器端高德地图 JS API Key |
| `AMAP_JS_SECURITY_CODE` | 视高德项目而定 | 高德 JS API 安全密钥 |
| `AMAP_WEB_SERVICE_KEY` | 可选 | 后端驾车路线、地点图片查询；不配置时使用前端直连或静态兜底 |
| `PORT` | 可选 | 服务端口，默认 `3030` |

高德 Key 的白名单应限制为本机地址或实际部署域名。`AMAP_JS_KEY` 会被返回给浏览器，`AMAP_WEB_SERVICE_KEY` 只在后端使用。

路线以“齐齐哈尔取车、齐齐哈尔还车”为主线，最后两天集中安排阿尔山：

## 页面功能

- 默认展示全程地图；切换日期后，当天路线和节点高亮，其余路线仍以灰色保留。
- 点击线路可查看驾车、步行等距离和预计时间，并可打开高德导航。
- 点击右侧行程卡片查看地点详情；长按卡片可将地点定位到地图中心。
- 点击图片可打开大图，并从大图跳转到图片原始来源。
- 图片失效时会按同组备用图自动切换；全部失效时保留来源入口。
- 动态线路会按飞机、火车、汽车图标快速播放，移动到下一站后等待点击“下一站”。
- 桌面端可以收起日期栏和行程卡片，也可以进入全屏地图；移动端行程卡片支持从底部拖动和收起。
- 天气使用 Open-Meteo；尚未发布或接口不可用时，页面显示明确的提示，不阻断行程页面。

## 开发与自检

语法检查：

```bash
npm run check
```

启动后可检查服务健康状态：

```bash
curl http://127.0.0.1:3030/api/health
```

正常返回：

```json
{"ok":true}
```

查看当前行程接口：

```bash
curl http://127.0.0.1:3030/api/trip
```

启动时服务会检查数据库中的 `itinerary_version`。当代码中的行程版本更新时，会自动刷新当前草案；不需要手动编辑 SQLite。日常只是修改页面内容时，重启一次 `npm start` 即可。

## 后端接口

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| `GET` | `/api/health` | 服务健康检查 |
| `GET` | `/api/trip` | 返回行程、日期、地点、节点和交通分段 |
| `GET` | `/api/config` | 返回地图公开配置和路线服务是否可用 |
| `GET` | `/api/route` | 后端代理高德驾车路线服务 |
| `GET` | `/api/place-photo` | 按关键词查询一张地点图片 |
| `GET` | `/api/october-photos` | 返回地点的十月图片及来源链接 |
| `GET` | `/api/weather` | 返回指定日期的天气预报 |
| `PATCH` | `/api/stops/:id` | 更新节点时间、标题、说明或状态 |

## 常见问题

### `npm start` 提示 Node 版本或 `node:sqlite` 错误

升级到 Node.js 22.5.0 或更高版本，再重新执行：

```bash
npm start
```

### 3030 端口被占用

先确认是否已经有一个旅行计划服务在运行：

```bash
curl http://127.0.0.1:3030/api/health
```

如果返回 `{"ok":true}`，直接打开页面即可，不需要重复启动。确实要换端口时：

```bash
PORT=3031 npm start
```

然后打开 <http://127.0.0.1:3031/>。

### 页面有行程但没有高德地图

确认 `.env` 中填写了 `AMAP_JS_KEY`，检查高德控制台的白名单和安全密钥配置，然后重启服务。浏览器已经打开旧页面时，重启后刷新一次页面。

### 地图有线路但没有真实驾车距离

确认 `.env` 中填写了 `AMAP_WEB_SERVICE_KEY`，并且该 Key 开通了对应 Web 服务。没有后端 Key 时，页面仍会保留路线和直线兜底，但不会保证每一段都有高德实际道路距离。

### 想重新初始化本地数据库

这会删除本地保存的行程修改，执行前先确认不需要保留编辑内容：

```bash
rm data/travel-plan.db
npm start
```

服务会自动创建数据库并写入当前行程草案。
